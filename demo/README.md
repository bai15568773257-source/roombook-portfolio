# ローカル画面プレビュー

Python標準ライブラリだけで、ポートフォリオ用の画面を確認するためのプレビューです。ユーザー、会議室、予約、メッセージ、操作履歴はすべて `server.py` 内の架空データです。パスワード・秘密鍵・社員データ・既存のデータベースは使用しません。

プロジェクトのルートで次を実行します。

```sh
python3 demo/server.py
```

ブラウザで <http://127.0.0.1:8765/> を開きます。終了はターミナルで `Ctrl+C`。ポートを変更する場合は `python3 demo/server.py --port 8766` とします。待受アドレスは変更できず、常に `127.0.0.1` です。外部公開やトンネル接続には使用しないでください。

## 確認できるもの

- 架空の管理者として開くダッシュボード、会議室一覧、予約一覧、時間軸、日付移動、月間カレンダー。
- 承認待ちのサンプル、ユーザー一覧、操作履歴などの表示。
- 日本語・中国語・英語の表示切替、ライト・ダーク表示。

画面上部には「DEMO」「架空データ・閲覧専用」を常時表示します。サンプル予約の日付は起動日の東京日付を基準に作成し、週末・祝日でも表示確認用の予約が含まれることがあります。実際の予約ルールを通して作成したデータではありません。

## 実行しないもの

- 予約・承認・ユーザー編集・削除・パスワード変更・メール送信・CSV出力。
- データベース接続、FastAPIの起動、外部サービス呼び出し、ファイルへの業務データ保存。

POST・PATCH・DELETE・PUTはすべてHTTP 405を返します。書き込みに関係するボタンを押すと閲覧専用の案内が表示されます。CSVのGETも、実システムでは保存や監査記録を伴うため、このプレビューでは提供しません。

`site/` のファイルを表示時に読み、HTML応答にデモ表示だけを追加します。実アプリの `app/main.py`、認証処理、設定ファイル、画面の原本を変更しません。ブラウザ側の表示設定はローカルストレージに保存される場合があります。

**これはUIプレビューです。実際のログイン認証、権限管理、データベース、予約の競合処理、メール配信が正常に動くことを検証・保証するものではありません。**
